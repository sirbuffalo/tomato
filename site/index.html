Tomato v

A statically typed, reference-counted, Python-like language compiled through LLVM. Its compiler is written in Tomato and compiles itself.

Try it in your browser Download Read the guide

def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(20))
print(7 // 2, 2 ** 10, 10 / 4)   # 3 1024 2.5

Python-shaped, typed

Indentation blocks and familiar syntax, with types checked before the program runs, even in code that never executes.

Native through LLVM

Programs compile to LLVM IR and link with a small C runtime. Only clang is needed to build the compiler and your programs.

Self-hosted

The compiler is written in Tomato. It builds itself to a byte-for-byte fixed point, and the checked-in IR bootstraps a machine that has only clang.

Exact where it matters

Whole numbers grow without limit or use a fixed width with overflow errors. float is 64-bit; rational is exact.

Versions

Tomato has two implementations. v0.x is the compiler written in Tomato (the tomato command). v-1.x is the Python bootstrap and interpreter (tomato-py), which also provides the repl.
