A statically typed, reference-counted language with indentation syntax, compiled through LLVM. Its compiler is written in Tomato and compiles itself.

def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(20))
print(10 / 4)   # 2.5

Familiar and typed

Indentation blocks and familiar syntax, with types checked at compile time.

Native through LLVM

Programs compile to LLVM IR and link with a small C runtime. Only clang is needed to build the compiler and your programs.

Self-hosted

The compiler is written in Tomato. It builds itself to a byte-for-byte fixed point, and the checked-in IR bootstraps a machine that has only clang.

Exact where it matters

Whole numbers grow without limit or use a fixed width with overflow errors. float is 64-bit; rational is exact.

Version

The current version is v: the compiler written in Tomato, the only implementation. The command is tomato.
