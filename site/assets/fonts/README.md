# Fonts

`quicksand-bold.woff2` is Quicksand Bold (the typeface of the tomato wordmark), subset to Basic Latin, Latin-1 and common punctuation and converted to WOFF 2. It is used for the page titles and section headings (`h1`, `h2`) in `style.css`.
