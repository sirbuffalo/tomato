Install

tar -xzf tomato-VERSION.tar.gz
cd tomato-VERSION
./install-native.sh
tomato version

This builds the compiler from the checked-in IR into ~/.tomato/native and links ~/.local/bin/tomato. Put ~/.local/bin on your PATH. An existing Python tomato command is kept as tomato-py.

Update

tomato update

Reads latest.json, checks the download against its SHA-256, and reinstalls when a newer version exists.
