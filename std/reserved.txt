# The module names std keeps for itself: every module std has, and the ones it may add later.
# One name per line, then `std` (a module std has now) or `planned` (not written yet). Blank lines and lines
# starting with # are ignored. The compiler's own copy of this list is compiler/src/modnames.tom; tests/run.sh
# checks the two against each other and against the files of std/.
#
# A seed may not provide a module with any of these names (tomato seed check refuses it), and a project file with the
# name of a `std` module shadows it with a warning. A project file with a `planned` name is allowed and silent today;
# once std adds the module, that file keeps shadowing it, with the warning. Adding a name here is cheap; removing one is a
# change to the promise of docs/language-design-review.md 9.1 (a decision), so add the names you may want.
