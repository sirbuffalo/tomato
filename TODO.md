- Make float `//` and `%` exact as in Python
  `x // y` on floats is `floor(x / y)` of the rounded quotient: `3.7 // 1e-5` is `370000.0` where Python gives `369999.0`, so `(x // y) * y + x % y == x` fails (10 of 1,500 random cases). A `%` whose result is zero loses the divisor's sign: `2.0 ** 64 % -1.0` is `0.0`, Python `-0.0`. Python computes `//` from `fmod` (`(x - fmod(x, y)) / y`, then corrected).
