# Tomato for VS Code

Syntax highlighting, bracket and indent rules, and snippets for `.tom` files. The grammar (`syntaxes/tomato.tmLanguage.json`, scope `source.tomato`) is a standard TextMate grammar, so it also works in Sublime Text, TextMate, IntelliJ (TextMate bundles) and GitHub Linguist.

Install from a folder: copy this directory to `~/.vscode/extensions/tomato-language`, or run `npx @vscode/vsce package` here and install the `.vsix`.
